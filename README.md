# Офис баланса

Рабочее пространство с пятью специалистами Gemini. Дизайн, русская навигация, шрифты и иллюстрации восстановлены с опубликованного сайта ученицы. Этот проект использует новую базу данных для аккаунтов, проектов, файлов и истории.

## Локальный запуск

Понадобятся Node.js 24, база PostgreSQL и ключ Gemini из [Google AI Studio](https://aistudio.google.com/api-keys).

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Перед запуском заполните `DATABASE_URL` и `GEMINI_API_KEY` в `.env.local`. Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) и зарегистрируйтесь. Сервер создаёт схему `balance_office` автоматически. Пользователю PostgreSQL нужны права на создание этой схемы и запись в неё.

## Деплой на Railway

1. Загрузите распакованный проект в GitHub. В Railway создайте проект и добавьте сервис из этого репозитория. Railway автоматически использует корневой `Dockerfile` с Node.js 24.
2. В том же проекте добавьте PostgreSQL. В **Variables** веб-сервиса установите `DATABASE_URL` в `${{Postgres.DATABASE_URL}}`, подставив имя вашего сервиса PostgreSQL. База остаётся в приватной сети проекта. [PostgreSQL на Railway](https://docs.railway.com/databases/postgresql)
3. Добавьте секрет `GEMINI_API_KEY` в **Variables** веб-сервиса. По желанию установите `GEMINI_MODEL`, список моделей `GEMINI_MODELS` через запятую и `REGISTRATION_CODE`, если регистрация должна быть по коду. Переменная `PORT` выделяется Railway автоматически.
4. В **Settings → Deploy** укажите путь проверки готовности `/health`. Он проверяет соединение с PostgreSQL. В **Settings → Networking → Public Networking** нажмите **Generate Domain**. [Проверка готовности](https://docs.railway.com/deployments/healthchecks), [публичный домен](https://docs.railway.com/networking/public-networking)
5. После публикации зарегистрируйтесь, создайте проект, загрузите документ и отправьте запрос Координатору. Откройте результат в истории после перезагрузки страницы.

Приложение отдаёт интерфейс и API с одного домена. Файлы, аккаунты, проекты и история хранятся в PostgreSQL и сохраняются при перезапуске веб-сервиса.

## Работа с документами

Поддерживаются PDF, DOCX, TXT, CSV, JPEG, PNG и WebP. Максимальный размер одного файла — 3 МБ. К одному запросу можно прикрепить до четырёх файлов. Большие текстовые документы разбиваются на фрагменты для поиска релевантных отрывков. Скан PDF отправляется в Gemini для визуального анализа.

Координатор выбирает специалистов, запускает их отдельными запросами в Gemini и формирует общий отчёт. Этапы и промежуточные выводы появляются по мере готовности. Итог и ход анализа доступны из истории.
